## Reproducing

From the repository root, offline, no key needed:

```powershell
python kit-td1/verify-data.py
python td1/references/compute_references.py
python td1/traces/merge_traces.py
python td1/traces/pivot_comparison.py
python kit-td1/skeleton-multi-llm-en.py --rates --state td1/traces-td1.jsonl
python kit-td1/skeleton-multi-llm-en.py --replay td1/traces-td1.csv --reference td1/reference-td1.csv --state replay.jsonl --out replay.csv
```

1. Checks the database against its manifest.
2. Rewrites `reference-td1.csv` and prints each SQL value next to an independent computation on the CSV files.
3. Rebuilds the merged traces from `traces/raw/` and `traces/merge-report.md`.
4. Rebuilds the models x questions view `results-pivot-td1.md`.
5. Prints the per-model results from the merged real traces.
6. Re-executes every stored SQL offline in the sandbox and recomputes the verdicts (rows labelled `replay`).

The model calls themselves are not re-run (one batch per account): the five commands are in
[`traces/README.md`](traces/README.md); they need the API keys in environment variables.
